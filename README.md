# Hello World

《三密三千大千世界》修行计划 · 事业线筑基期作品

## 项目简介

本仓库用于验证 Python / Anaconda / Jupyter 开发环境是否正常，是量化交易学习之路的第一个里程碑。

## 内容

- `hello_world.ipynb` — Jupyter Notebook，包含环境验证代码（Python 版本、可执行路径、系统信息）

## 环境

- Python 3.14.6（Anaconda）
- JupyterLab 4.5.9
- Git 2.55.0

## 运行方式

```bash
jupyter lab
```

打开后运行 `hello_world.ipynb` 即可。

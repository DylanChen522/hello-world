# Markdown 基础教程

《三密三千大千世界》· 环境搭建模块 · 学习笔记

> Markdown 是一种轻量级标记语言，用简单符号排版，**一份文件同时是"源码"和"成品"**。
> 它是程序员写文档、记笔记、写 README 的事实标准，也是 GitHub 的默认文档格式。

---

## 1. 为什么学 Markdown？

| 优势 | 说明 |
|------|------|
| 轻量 | 纯文本，任何编辑器都能打开 |
| 通用 | GitHub / 飞书 / 语雀 / Typora 全支持 |
| 专注 | 只写内容，不管排版，格式自动生成 |
| 版本友好 | 纯文本天然适合 Git 管理（可 diff） |

**一句话**：Markdown 让你「只关心写什么」，不操心「长什么样」。

## 2. 核心语法（90% 场景够用）

### 2.1 标题
```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```
> `#` 后要有空格；层级从 1 到 6，最多六级。

### 2.2 强调
```
**加粗**    → **加粗**
*斜体*      → *斜体*
~~删除线~~  → ~~删除线~~
`行内代码`  → `行内代码`
```

### 2.3 列表
```
无序列表：
- 项目一
- 项目二

有序列表：
1. 第一步
2. 第二步

任务清单：
- [ ] 待办
- [x] 已完成
```

### 2.4 链接与图片
```
[链接文字](https://github.com)

![图片描述](图片地址)
```

### 2.5 代码块
````
```python
print("Hello, Quant World!")
```
````
> 语言名（python）用于语法高亮；不写也可。

### 2.6 引用
```
> 这是一段引用
> 多行引用继续用 >
```

### 2.7 表格
```
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 数据 | 数据 | 数据 |
```

### 2.8 分割线与换行
```
---        ← 分割线（三个以上横线）
行尾两个空格 + 回车 → 换行（不空行）
```

## 3. 进阶语法（提升笔记质量）

### 3.1 锚点 / 目录
GitHub 自动为标题生成锚点，可用链接跳转：
```
[跳转到第2节](#2-核心语法90-场景够用)
```

### 3.2 嵌套列表
```
1. 第一层
   - 缩进四个空格
   - 变成子项
2. 第二层
```

### 3.3 数学公式（部分平台支持）
```
行内公式：$E = mc^2$
块级公式：
$$
\sum_{i=1}^{n} x_i
$$
```

### 3.4 HTML 混用
```html
<div align="center">居中内容</div>
<details><summary>折叠内容</summary>点开看详情</details>
```

## 4. 学习笔记库约定（本库规范）

建库遵循以下约定，保证笔记可维护、可检索：

```
notes/
├── README.md          ← 索引页（必读入口）
├── 01-python/         ← 按主题分类
│   └── 01-基础语法.md
├── 02-git/            ← 每个主题一个目录
├── 03-markdown/
└── 99-模板/           ← 笔记模板
    └── 笔记模板.md
```

**命名规范**：`数字-名称`（数字控制排序，名称表意）
**笔记模板**：开头写「主题 / 日期 / 状态 / 要点」，正文用标题分级。
